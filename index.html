Arquitetura Pensada no Cliente

O projeto foi construído sobre três pilares fundamentais.

Velocidade Extrema

Construído como Single Page Application (SPA), o sistema não recarrega a página. Navegação instantânea que evita desistências no momento do agendamento.

100% Personalizado

Esqueça templates prontos. O UI/UX foi desenhado sob medida para a identidade visual da barbearia, garantindo uma experiência premium e exclusiva.

Integração WhatsApp

Comunicação automatizada usando a Evolution API. Lembretes automáticos 1h antes do corte e avisos instantâneos de aprovação de horários.

A Experiência do Cliente

A ideia aqui foi fazer um fluxo direto ao ponto. O dono do salão pediu para que a agenda fosse dinâmica: se o cliente escolhe um corte simples, o sistema reserva 20 minutos; se for uma química, trava a agenda por 1h30. Tudo calculado sozinho.

  • Sinal via Pix: Para dar um ar mais profissional e acabar com a dor de cabeça de cliente que marca e não vai, implementei a cobrança de um sinal via Pix com QR Code direto na tela.
  • Blindagem no Banco: Deu um trabalho legal, mas fiz uma trava no Firebase: se dois clientes tentarem "roubar" o mesmo horário no mesmo milissegundo, o sistema bloqueia um deles para não dar conflito.
  • Painel Próprio: O cliente tem um perfil para ver o que já foi cortado e acompanhar se o barbeiro já aprovou o Pix dele.

A Ferramenta do Barbeiro

O painel dele foi pensado para ser usado de forma rápida no celular, entre um corte e outro. O cliente pediu autonomia total, então deixei a gestão da agenda nas mãos dele.

  • Visão Clara do Dia: Uma tabela simples onde ele bate o olho e sabe quem é o próximo. Se alguém sumir ou desmarcar, ele resolve ali mesmo.
  • Aprovações na Hora: Quando cai um agendamento novo com o Pix pago, fica pendente nesta aba. Ele confere na conta bancária e libera com um clique.
  • Ele manda na Agenda: Ele mesmo cria a grade de horários, abre vagas extras de fim de ano ou apaga horários que precisar tirar de folga.
Integração WhatsApp Evolution API (Node.js)

A Mágica da Automação

Foi aqui que o projeto subiu de nível. Para reduzir as faltas, integrei o sistema com a Evolution API. Basicamente, a barbearia conversa com o cliente no zap sem o barbeiro precisar digitar uma única palavra.

  • Acabaram os Esquecimentos: Criei um script que varre o banco de dados e avisa o cliente no WhatsApp exatos 60 minutos antes do corte. Salvou a agenda do salão várias vezes.
  • Respostas Vapt-Vupt: Assim que o barbeiro dá o "ok" no pagamento, o sistema já dispara o zap confirmando tudo pro cliente.
  • Prevenção de Falhas (Fallback): Como sabemos que APIs e servidores podem cair de vez em quando, fiz um plano B de segurança. Se o servidor principal falhar, o código gera um link nativo do WhatsApp e envia do mesmo jeito.
